# 90-second demo script

## 0–15 seconds — problem

“AI agents can remember our preferences, but we usually cannot tell when a memory silently changes an action. ShadowRecall is a memory influence firewall.”

## 15–35 seconds — run the twins

Enter: **Schedule the project review for the earliest available time.**

“The exact same instruction goes to two controlled agents. One can retrieve memory; its amnesiac twin cannot. Neither is allowed to execute anything.”

Click **Analyze influence**.

## 35–60 seconds — show the divergence

“The remembering agent chose tomorrow morning. The amnesiac agent chose today afternoon. ShadowRecall compares structured action fields, not superficial wording, and pauses the plan because the date and time changed.”

## 60–78 seconds — attribution

“It then removes relevant memories one at a time. Removing this morning-meeting preference makes the agents agree, so ShadowRecall identifies it as the likely influence with a transparent confidence score.”

## 78–90 seconds — close

“Existing tools show what AI remembers. ShadowRecall shows whether memory changed what AI was about to do—before it happens.”

Do not spend demo time on setup, source code, or every UI label. End on the influence attribution card.
